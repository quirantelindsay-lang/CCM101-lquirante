# AWS Research - Amazon Web Services

## Brief Overview
Amazon Web Services (AWS) is a secure cloud services platform offering computing power, database storage, content delivery, and other functionality to help businesses scale and grow[cite: 1]. Launched in 2006[cite: 1], it is one of the pioneers and largest providers in the cloud computing market.

## Global Infrastructure
* **Regions:** Isolated geographic areas containing multiple data centers[cite: 1].
* **Availability Zones (AZs):** Distinct locations within a region with independent power, cooling, and networking infrastructure[cite: 1].

## Cloud Management Console
The AWS Management Console is a web-based interface that allows users to manage and monitor all AWS services, view resource status, and configure security settings[cite: 1].

## Four (4) Core Services
1. **Amazon EC2 (Elastic Compute Cloud):** Provides scalable computing capacity in the cloud[cite: 1].
2. **Amazon S3 (Simple Storage Service):** Object storage built to store and retrieve any amount of data[cite: 1].
3. **Amazon RDS (Relational Database Service):** Managed relational database service supporting engines like MySQL, PostgreSQL, and SQL Server[cite: 1].
4. **Amazon VPC (Virtual Private Cloud):** Provisions a logically isolated section of the AWS cloud to run resources in a secure network[cite: 1].

## Three (3) Advantages
* **Massive Ecosystem:** The broadest and deepest set of cloud capabilities and services[cite: 1].
* **High Reliability & Security:** Built to meet rigorous security compliance standards for global enterprises[cite: 1].
* **Flexibility:** Allows companies to choose the exact operating systems, programming languages, and databases for their projects[cite: 1].

## Typical Enterprise Use Cases
* Large-scale web applications and global e-commerce platforms[cite: 1].
* Big data analytics and data warehousing[cite: 1].
* Enterprise disaster recovery and backup systems[cite: 1].
