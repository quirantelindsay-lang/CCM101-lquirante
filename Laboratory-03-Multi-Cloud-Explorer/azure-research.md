# Azure Research - Microsoft Azure

## Brief Overview
Microsoft Azure is a comprehensive cloud computing public platform created by Microsoft[cite: 1]. Launched in 2010[cite: 1], it provides a wide range of integrated cloud services including analytics, computing, database, mobile, networking, storage, and web.

## Global Infrastructure
* **Regions:** Dozens of localized geographic regions worldwide[cite: 1].
* **Availability Zones:** Resiliency-focused locations within regions made up of unique physical data centers[cite: 1].

## Cloud Management Console
The Azure Portal is a unified web-based console that lets users build, manage, and monitor everything from simple web apps to complex cloud deployments[cite: 1].

## Four (4) Core Services
1. **Azure Virtual Machines:** On-demand, scalable computing resources running Windows or Linux[cite: 1].
2. **Azure Blob Storage:** Scalable object storage for unstructured data and massive data backups[cite: 1].
3. **Azure SQL Database:** Fully managed relational database service based on the SQL Server engine[cite: 1].
4. **Azure Virtual Network (VNet):** Enables Azure resources to securely communicate with each other, the internet, and on-premises networks[cite: 1].

## Three (3) Advantages
* **Seamless Microsoft Integration:** Perfect synergy with local Windows Server, Active Directory, and Office 365 environments[cite: 1].
* **Hybrid Cloud Consistency:** Strong hybrid capabilities allowing seamless integration between on-premises datacenters and the cloud[cite: 1].
* **Enterprise Trust:** Backed by enterprise-grade security and compliance agreements[cite: 1].

## Typical Enterprise Use Cases
* Hybrid cloud setups for corporate offices using legacy Microsoft systems[cite: 1].
* Enterprise identity management via Microsoft Entra ID[cite: 1].
* Scalable .NET application development and hosting[cite: 1].
