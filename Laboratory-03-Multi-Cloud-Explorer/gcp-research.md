# GCP Research - Google Cloud Platform

## Brief Overview
Google Cloud Platform (GCP), offered by Google, is a suite of cloud computing services that runs on the same infrastructure that Google uses internally for its end-user products, such as Google Search, Gmail, and YouTube[cite: 1]. It was launched in 2008[cite: 1].

## Global Infrastructure
* **Regions:** Specific geographic areas where cloud resources are hosted[cite: 1].
* **Zones:** Deployment areas for Google Cloud resources within a region, designed to be independent failure domains[cite: 1].

## Cloud Management Console
The Google Cloud Console provides a web-based user interface to manage projects, configure resources, view billing details, and deploy applications[cite: 1].

## Four (4) Core Services
1. **Google Compute Engine:** High-performance scalable virtual machines running in Google's data centers[cite: 1].
2. **Google Cloud Storage:** Secure and durable object storage for developers and enterprises[cite: 1].
3. **Cloud SQL:** Fully managed relational database service for MySQL, PostgreSQL, and SQL Server[cite: 1].
4. **Google Cloud VPC:** Virtual Private Cloud providing scalable and flexible networking for cloud resources[cite: 1].

## Three (3) Advantages
* **Data Analytics & AI Leadership:** Industry-leading tools for big data processing, machine learning, and AI research (such as Vertex AI)[cite: 1].
* **Kubernetes Innovation:** Google is the original creator of Kubernetes, making container orchestration native and highly efficient[cite: 1].
* **Global Network:** Utilizes Google's private, high-speed fiber-optic global network[cite: 1].

## Typical Enterprise Use Cases
* Data analytics, data lakes, and heavy data-processing pipelines[cite: 1].
* Machine learning model training and AI research deployments[cite: 1].
* Modern microservices hosted on Kubernetes (GKE)[cite: 1].
