# Mission Reflection

1. **Which cloud platform impressed you the most?**
Google Cloud Platform impressed me the most due to its powerful data analytics capabilities and its origin as the creator of Kubernetes, which simplifies container deployment and management.

2. **What similarities exist among AWS, Azure, and GCP?**
All three major cloud providers share core structural similarities: they all offer scalable on-demand compute instances, secure object storage tiers, virtual private networking capabilities, and robust global infrastructure regions distributed worldwide.

3. **How do business requirements influence cloud platform selection?**
Business requirements drive technical choices directly. For instance, an organization deeply embedded in the Microsoft ecosystem will naturally lean toward Azure for license compatibility, whereas an AI research firm will prioritize GCP or AWS for specialized GPU/TPU compute instances.

4. **What did you learn from acting as a Cloud Solutions Consultant?**
Acting as a consultant taught me that technical architecture decisions are never one-size-fits-all; they must balance budget constraints, developer familiarity, compliance, and specific performance workloads.

5. **How has your GitHub Cloud Computing Portfolio improved after completing this mission?**
Completing this mission significantly strengthened my portfolio by incorporating comprehensive multi-cloud comparative analyses, structured technical markdown documentations, and well-defined architecture decision matrices.
