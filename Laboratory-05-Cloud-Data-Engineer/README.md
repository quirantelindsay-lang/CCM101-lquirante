## Mission Overview
This laboratory activity focuses on transitioning from traditional web server containers to specialized data engineering tasks. The mission involves deploying a custom S3-compatible Object Storage server using MinIO to handle massive amounts of unstructured data, specifically user-uploaded images for a client's photo-sharing application.

## Objectives
* Differentiate between Block, File, and Object Storage.
* Deploy an S3-compatible Object Storage server (MinIO) using Docker.
* Access a cloud service via a web interface using port forwarding.
* Create a storage bucket and upload objects (files) to the cloud.
* Document cloud storage operations using Markdown.

## Tools Used
* KillerCoda Playground (Ubuntu/Docker environment)
* Docker
* MinIO Object Storage Server
* Markdown
* GitHub

## Skills Learned
* Containerizing storage services using advanced Docker commands.
* Implementing environment variables (`-e` flags) for secure container initialization.
* Configuring port mapping for API and Web Console access.
* Managing and creating cloud storage buckets via web-based management consoles.
