# Laboratory Activity 7: The Cloud Operations Engineer

## Mission Overview
Stepping into the role of a Cloud Operations Engineer at CloudNova Technologies to establish a host performance baseline, deploy a containerized Nginx web server, simulate traffic, and inspect application logs and live container metrics[cite: 1, 2, 3].

## Objectives
* Utilize native Linux command-line tools to monitor host CPU, Memory, and Disk capacity[cite: 1, 2].
* Deploy a web container and track its real-time performance using Docker metrics[cite: 1, 3].
* Generate web traffic and extract application access logs for analysis[cite: 1, 3].
* Translate raw performance data into a readable technical report using Markdown[cite: 1, 3].
* Expand the professional GitHub Cloud Computing Portfolio[cite: 1, 2].

## Monitoring Commands Executed
* `free -h` - Checks available RAM[cite: 2]
* `df -h` - Checks available disk space[cite: 2]
* `top` - Displays active processes and CPU usage[cite: 2]
* `docker run` - Deploys the Nginx web server container[cite: 3]
* `curl` - Simulates HTTP requests and traffic[cite: 3]
* `docker logs` - Extracts container access logs[cite: 3]
* `docker stats` - Streams real-time container performance metrics[cite: 3]

## Skills Learned
* Establishing server hardware performance baselines using Linux CLI utilities.
* Simulating user traffic and intentionally triggering/capturing HTTP error codes[cite: 4].
* Analyzing container logs to diagnose runtime behavior[cite: 4].
* Tracking real-time resource efficiency with container monitoring dashboards[cite: 4].
