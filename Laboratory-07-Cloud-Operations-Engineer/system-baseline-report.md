# System Baseline Report - Host Server

## Host Resource Overview
* **Total RAM Available:** 1903.2 MiB (1.9 GiB)[cite: 2, 5]
* **Total Storage Capacity (Root `/` File System):** 19G (`/dev/vda1`)

## Critical Infrastructure Analysis
Checking disk space is critical before a massive traffic surge because insufficient storage can cause application logs to fail, database writes to crash, and the operating system to run out of ephemeral swap space, resulting in total service downtime[cite: 2].
