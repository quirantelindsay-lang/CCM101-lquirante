## Cloud Provider Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
| :--- | :--- | :--- | :--- |
| **Compute** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Storage** | Amazon S3 | Azure Blob Storage | Cloud Storage |
| **Networking** | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |
| **Identity and Access Management (IAM)** | AWS IAM | Microsoft Entra ID (Azure AD) | Cloud IAM |

### Guide Questions

**1. Which cloud provider offers the broadest range of services? Explain your answer.**
Amazon Web Services (AWS) offers the broadest range of services. Dahil ito ang pinakaunang naging sikat at pinakamatagal na sa industriya, nakapag-develop sila ng pinakamalaking ecosystem ng cloud tools at services kumpara sa iba.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?**
Microsoft Azure ang pinakamagandang i-recommend. Dahil gawa rin ito ng Microsoft, mayroon itong seamless at native integration sa mga sikat na enterprise tools tulad ng Windows Server, Office 365, at Active Directory.

**3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?**
Google Cloud Platform (GCP) ang pinakakilala pagdating sa mga serbisyong ito. Ang Google mismo ang nag-develop ng Kubernetes (para sa container orchestration) at TensorFlow (para sa machine learning), kaya napakalakas ng suporta nila rito.

**4. What similarities did you observe among the three cloud providers?**
Lahat silang tatlo ay nag-aalok ng pare-parehong core infrastructure services tulad ng Compute, Storage, Networking, at IAM. Pare-pareho rin silang gumagamit ng pay-as-you-go na billing model para sa madaling pag-scale ng resources.
