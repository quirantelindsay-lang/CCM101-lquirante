## Mission Overview
This mission involves investigating cloud infrastructure components, understanding Linux server resources, and preparing technical documentation for cloud deployment.

## Objectives
* Explain the major components of cloud infrastructure.
* Investigate hardware and software resources in Linux.
* Differentiate compute, storage, networking, and identity resources.
* Create professional technical documentation using Markdown.

## Cloud Infrastructure Components
* Compute Resources (e.g., CPU, RAM)
* Storage Resources (e.g., Disk space)
* Networking Resources (e.g., IP Address, Hostname)
* Operating System (e.g., Linux Ubuntu)

## Skills Learned
I learned how to navigate a cloud-based Linux environment, extract system specifications, compare major cloud providers, and create a foundational cloud architecture diagram.

## Challenges Encountered
Determining the exact equivalent services across AWS, Azure, and GCP required careful comparison, and organizing the technical documentation in Markdown needed precise formatting.
