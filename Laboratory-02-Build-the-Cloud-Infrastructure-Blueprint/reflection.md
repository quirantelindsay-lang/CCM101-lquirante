## Mission Reflection

### 1. Which cloud infrastructure component do you think is the most important? Why?
The compute resource is arguably the most important component because it acts as the primary engine that executes applications and processes workloads. Without compute power, stored data remains static and networks have nothing to transmit, making it the core driver of any cloud architecture.

### 2. How does Linux support cloud computing?
Linux serves as the foundational operating system for the vast majority of cloud infrastructure, powering virtual machines, containers, and hypervisors. Its stability, open-source flexibility, and powerful command-line interface allow cloud engineers to efficiently provision, configure, and manage cloud servers remotely.

### 3. Why is technical documentation important before deploying infrastructure?
Technical documentation provides a clear blueprint and standardized reference that ensures every design decision is justified, security measures are met, and team members understand the architecture. It prevents costly misconfigurations and serves as a vital guide for future scaling and troubleshooting.

### 4. What new skills did you learn during this laboratory activity?
Throughout this mission, I developed practical skills in inspecting server hardware using Linux terminal commands, analyzing equivalent cloud services across major providers like AWS, Azure, and GCP, and mapping out a foundational cloud architecture diagram.

### 5. How has your GitHub portfolio improved after completing this mission?
Completing this mission significantly improved my portfolio by establishing a structured, version-controlled workspace that organizes technical reports, architectural diagrams, and documentation in a professional manner. It demonstrates my ongoing growth and readiness as a cloud engineer.
