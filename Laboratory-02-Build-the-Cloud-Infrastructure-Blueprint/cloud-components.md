**Compute Resources**
* **Purpose:** Ito ang nagsisilbing "utak" na nagpo-process ng data, nagpapatakbo ng applications, at nagbibigay ng memory.
* **Importance in Cloud Computing:** Nagbibigay ito ng on-demand processing power para mag-run ng virtual machines nang hindi na kailangang bumili ng pisikal na hardware.
* **Relation to KillerCoda:** Nakita natin ang compute resources ng KillerCoda server noong ginamit ang commands na `lscpu` (para sa CPU cores) at `free -h` (para sa RAM).

**Storage Resources**
* **Purpose:** Ito ang pinaglalagyan at pinagsi-save-an ng mga files, databases, at operating system.
* **Importance in Cloud Computing:** Tinitiyak nito na mayroong scalable, secure, at permanenteng lalagyan ang mga data sa cloud na pwedeng ma-access kahit kailan.
* **Relation to KillerCoda:** Na-check natin ang storage resource ng KillerCoda environment noong nag-run tayo ng `df -h` para makita ang disk capacity at mounted file systems.

**Networking Resources**
* **Purpose:** Ito ang nagkokonekta sa iba't ibang cloud resources, servers, at users para makapag-usap sila at magpalitan ng data.
* **Importance in Cloud Computing:** Kung walang networking, hindi natin ma-a-access ang cloud servers mula sa internet at hindi magkaka-connect ang mga cloud architecture.
* **Relation to KillerCoda:** Ang network resources ng KillerCoda ay na-verify natin gamit ang commands na `hostname` at `ip a` para malaman ang IP address nito.

**Operating System**
* **Purpose:** Ito ang main software system na nagma-manage ng server hardware at nag-a-allow sa ibang cloud applications na tumakbo.
* **Importance in Cloud Computing:** Ito ang nagsisilbing tulay at pinaka-foundation sa pagitan ng cloud infrastructure at ng cloud engineer para makapag-manage ng resources.
* **Relation to KillerCoda:** Ang OS ng KillerCoda ay ang mismong Linux distribution na in-access natin, na nakumpirma noong ni-run ang `cat /etc/os-release` at `uname -r`.
